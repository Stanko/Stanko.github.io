Well I saw a pretty nice mockup on [Dribbble](https://dribbble.com/shots/2311260-Day-1-Sign-Up-and-Login-Animated-Download-Template)
and decided to make it for fun. It didn't include a mobile/responsive solution, so I came up with my own.

<Image 
  src='./animated-onboarding.png'
  alt="Animated onboarding demo" 
  link="https://muffinman.io/animated-onboarding/"
  size="wide"
/>

Check the [demo](https://muffinman.io/animated-onboarding/).

This is a pure CSS solution - it uses the `:target` selector for changing states.
Find more about `:target` on [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/:target).
This is neat, as it also can be bookmarked in both states, and browser buttons work too.

Grab the code on [GitHub](https://github.com/Stanko/animated-onboarding).
