It is nice to use `post.excerpt` instead of `post.content`
on your Jekyll home page, but then users can't see if there 
is more to read until they open the whole post.

To add `Read more` link, you can use this simple snippet.

```
{% if post.excerpt != post.content %}
    <a href="{{ site.baseurl }}{{ post.url }}">Read more</a>
{% endif %}
```
